# HomeStorage

Aplikasi web penyimpanan file dan catatan privat (Single-Page App + Backend Node.js/Express & SQLite).

## Fitur
- **Hero Section:** Desain modern, badge privasi, kartu statistik interaktif.
- **Upload File:** Unggah file via klik atau *drag-and-drop*.
- **Catatan Penting:** Simpan catatan dengan dukungan shortcut `Ctrl+Enter`.
- **Pencarian Real-Time:** Filter file dan catatan secara instan.
- **Export Data:** Unduh seluruh backup data dalam satu klik format JSON.
- **Backend API & SQLite:** Penyimpanan server-side menggunakan Express dan SQLite.

---

## Cara Menjalankan

### 1. Jalankan Backend
```bash
cd backend
npm install
npm start
```
Server berjalan di `http://localhost:3000`.

### 2. Buka Frontend
Buka file `index.html` di browser atau serve menggunakan static file server.
